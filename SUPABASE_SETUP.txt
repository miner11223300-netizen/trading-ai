НАСТРОЙКА ОБЩЕЙ БАЗЫ SUPABASE

1. Создайте проект Supabase.
2. В Project Settings → Database найдите Connection string → URI.
3. Скопируйте строку подключения PostgreSQL.

Streamlit Cloud → App → Settings → Secrets:
DATABASE_URL = "ВАША_POSTGRESQL_URI"
TELEGRAM_BOT_TOKEN = "ВАШ_ТОКЕН"
TELEGRAM_CHAT_ID = "ВАШ_CHAT_ID"

GitHub → Settings → Secrets and variables → Actions:
Создайте секрет DATABASE_URL с тем же значением PostgreSQL URI.
Оставьте TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID как прежде.

Не вставляйте URI в исходный код и не отправляйте его в чат.
После настройки перезапустите Streamlit и запустите GitHub Actions вручную.
Если переменная DATABASE_URL не задана хотя бы в одном компоненте,
он продолжит использовать отдельную локальную SQLite-базу.
